# User Profile & Activity Explorer

Responsive JavaScript assignment built with HTML, CSS and ES modules, based on the supplied assignment requirements.

## Features
- Validate User ID (1–10) before sending a request
- Random User button
- Fetch user details and posts using async/await
- Loading and error states
- Profile card with name, username, email, phone, company, city and website
- First three posts with expandable comments
- Bookmark users in localStorage and reload them from the sidebar

## Folder structure
- `index.html`
- `style.css`
- `src/api.js`
- `src/dom.js`
- `src/app.js`

## Run locally
Because this project uses JavaScript ES modules, serve it with a local server. In VS Code, use Live Server, or run `python -m http.server` from this folder and visit `http://localhost:8000`.

API: https://jsonplaceholder.typicode.com/
